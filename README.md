# BT Tech Solutions website

Static site for BT Tech Solutions (Madison, WI). Hosted on Netlify, deployed from this GitHub repository.

## Pages
- `index.html` — homepage with the contact form ("contact")
- `thank-you.html` — shown after the contact form is sent
- `request-update.html` — client request form ("update-request")
- `request-received.html` — shown after a client request is sent

## Making changes
Edit a file and commit it to the `main` branch. Netlify publishes the change automatically.
